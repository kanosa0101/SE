# CVInsight 顶会热词统计平台设计规格

日期：2026-09-18

## 目标

在 `102400330` 仓库中重新实现一个可运行、可测试、可部署的 CVInsight Web 平台，完成本次作业要求的 CVPR、ICCV、ECCV 论文获取、管理、关键词统计、热点可视化和趋势动画功能。

Stitch 生成的页面只作为需求和视觉参考，不复制其中的 HTML、CSS、JavaScript 或虚构统计结果。最终代码由 Vue 3 和 FastAPI 独立实现，并通过 SQLite 持久化数据。

## 范围

### 本次实现包含

1. 论文数据导入
   - 支持单篇论文标题在线检索。
   - 支持 CSV/TXT 批量导入。
   - 保存标题、摘要、作者、会议、年份、关键词和原文链接。
   - 保存数据来源及来源链接，便于博客中说明数据获取方式。
2. 论文列表管理
   - 支持标题精确查询。
   - 支持标题、论文编号、作者和关键词模糊查询。
   - 支持论文新增、编辑、删除和详情查看。
   - 本地无结果时触发在线检索，并允许用户确认后入库。
3. 热门方向分析
   - 默认展示当前筛选范围内的 Top 10 热门关键词。
   - 页面明确称为“热门关键词”；只有经过固定词典归并后才称为“研究方向”。
4. 关键词图谱
   - 节点表示关键词，节点大小表示论文覆盖数。
   - 边表示关键词在同一篇论文中的共现次数。
   - 点击节点后联动展示相关论文。
5. 热度走势对比
   - 支持 CVPR、ICCV、ECCV 单独或并列筛选。
   - 支持按年份查看关键词热度。
   - 支持 ECharts 播放、暂停、重置和速度调整。
6. 工程与交付边界
   - 项目仓库保留 `README.md`、`codestyle.md`、设计/实施计划和部署说明。
   - PSP、AI 协作记录和博客草稿属于个人课程提交材料，保留在本地但不纳入 Git。
   - `dev` 分支开发，完成后再按提交者需要合并 `main`；后端测试、前端构建检查和部署配置作为项目验收依据。

### 明确不做

- 不实现登录、权限、支付、社交或用户画像。
- 不把 Stitch 代码直接复制到仓库，也不使用原型工具生成的代码作为实现代码。
- 不把未经来源核验的论文数量、录用状态、会议机构或预测数字写入正式统计。
- 不使用大语言模型直接替代可复现的关键词统计算法。
- 不在第一版中实现全量论文实时抓取任务队列；批量导入采用可观察的同步处理，并返回每条记录的成功或失败原因。

## 技术架构

```text
Vue 3 + Vite + Vue Router + Axios + ECharts
                         │ REST/JSON
FastAPI + Pydantic + SQLAlchemy
                         │
                       SQLite
```

前端负责页面、筛选状态、图表和交互；后端负责校验、持久化、关键词提取、统计和在线检索；SQLite 作为嵌入式数据库，便于本地运行和云服务器部署。

生产环境由 FastAPI 提供构建后的 Vue 静态文件和 `/api` 接口。Nginx 配置作为可选反向代理提供，应用本身不依赖特定操作系统路径。

## 数据模型

### `papers`

| 字段 | 说明 |
| --- | --- |
| `id` | 内部主键 |
| `title` | 论文标题，必填 |
| `paper_code` | 会议论文编号或外部标识，可为空 |
| `abstract` | 摘要，可为空 |
| `authors` | 作者文本 |
| `conference` | `CVPR`、`ICCV` 或 `ECCV` |
| `year` | 发表年份 |
| `source` | `CVF`、`fixture`、`manual`、`openalex` 等 |
| `source_url` | 原文或数据来源链接 |
| `crawled_at` | 抓取时间，可为空 |
| `parser_version` | 解析器版本，可为空 |
| `created_at` | 入库时间 |
| `updated_at` | 更新时间 |

### `keywords`

保存归一化后的关键词名称。关键词统一转小写、去除标点和多余空格，并通过别名词典合并明确同义写法，例如 `vlm` 与 `vision language model`。

### `paper_keywords`

保存论文与关键词的关系，包括 `paper_id`、`keyword_id`、`score` 和 `method`。`method` 区分原始关键词与 TF-IDF 提取结果。

## 统计口径

默认热度使用论文覆盖率，而不是词在摘要中出现的原始次数：

```text
heat(keyword, conference, year)
  = 包含 keyword 的论文数 / 该会议该年份论文总数 × 1000
```

这样可以减少不同年份论文数量差异带来的偏差。趋势页使用同一口径，显示相邻年份的热度差；当前年份没有前一年数据时不显示增长率，避免除零和虚假爆发。

关键词来源按以下顺序处理：

1. 原始数据中有关键词时优先使用原始关键词。
2. 没有关键词但有标题和摘要时，使用英文停用词过滤、词形归一和 TF-IDF 提取候选词。
3. 所有自动提取结果保存 `method=tfidf`，页面和博客不把它伪装成论文作者提供的关键词。

图谱边权为两关键词在同一篇论文中共同出现的次数，只展示选定范围内的高频节点和边，避免图谱不可读。

## 数据来源策略

正式数据使用可追溯的公开会议元数据或教师提供的数据集。导入文件必须至少包含标题、会议和年份；其他字段缺失时保留为空并在界面中显示状态。

单篇在线检索使用公开学术元数据检索适配器，适配器返回标题、摘要、关键词、作者和原文链接，并在记录中保存实际来源。在线检索失败时返回可解释的错误，不生成虚构论文信息。

仓库中的开发种子数据如果存在，必须标注为 `fixture` 或 `demo`，只用于页面和测试演示，不用于课程提交材料中的正式统计结论。

## 后端接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/health` | 健康检查 |
| `GET` | `/api/papers` | 分页、精确/模糊查询和筛选 |
| `GET` | `/api/papers/{id}` | 查询论文详情 |
| `POST` | `/api/papers` | 新增论文 |
| `PUT` | `/api/papers/{id}` | 编辑论文 |
| `DELETE` | `/api/papers/{id}` | 删除论文 |
| `POST` | `/api/papers/import` | 上传 CSV/TXT 并批量入库 |
| `GET` | `/api/papers/lookup` | 本地无结果时在线检索 |
| `GET` | `/api/stats/overview` | 总论文数、会议数和年份范围 |
| `GET` | `/api/stats/topics` | Top 10 热门关键词 |
| `GET` | `/api/stats/graph` | 关键词节点和共现边 |
| `GET` | `/api/stats/trends` | 多会议、多年份热度序列 |
| `GET` | `/api/stats/topics/{keyword}/inspector` | 主题详情、相关词和代表论文 |
| `GET` | `/api/stats/evolution` | 返回年度 Top 关键词帧 |
| `GET` | `/api/stats/quality` | 字段覆盖、来源和会议年份矩阵审计 |
| `GET` | `/api/papers/export` | 按筛选条件导出 CSV/BibTeX |

所有接口使用 Pydantic schema 校验会议枚举、年份范围、空标题和分页参数。删除操作只删除本地数据，不影响外部来源。

## 前端页面

Vue 路由固定为：

- `/`：总览，显示统计卡片、Top 10 和关键词图谱。
- `/trends`：趋势对比，显示筛选器、时间轴和 ECharts 动画。
- `/papers`：论文管理，显示搜索、筛选、表格、详情抽屉和编辑表单。
- `/import`：论文导入，显示单篇检索、批量上传、预览和逐条处理结果。
- `/about`：数据来源、统计公式、关键词算法和限制说明。

总览页支持主题检查器；趋势页支持年度热词演变播放；论文库支持 CSV/BibTeX 导出；导入页和说明页展示数据质量审计。

视觉风格重新用 Vue/CSS 实现“深色科研观测站”：深午夜蓝背景、青色主强调、琥珀色增长、珊瑚色下降、细边框、Noto Serif 标题和等宽数据标签。页面重点是数据可读性，不使用 Stitch 的代码或静态数据。

## 测试与验收

后端至少覆盖：

- 空标题和非法会议被拒绝。
- 同一论文重复导入不会产生重复记录。
- 精确标题和关键词模糊查询结果正确。
- 关键词热度在不同年份论文总数不同的情况下按覆盖率计算。
- 共现图谱的节点和边由真实关系生成。
- 本地无结果时在线检索失败会返回明确错误。

前端验收包括：

- `npm run build` 成功。
- 五个路由可以正常加载。
- 论文筛选、编辑、删除、导入、关键词点击和趋势播放能够完成可见状态变化。
- 空数据、加载中和接口失败状态有清晰提示。
- 主题检查器、年度演变、质量审计和导出操作均消费真实 API 数据，不使用页面固定统计数字。
- CVF 抓取样本保留 source、source_url、crawled_at 和 parser_version，并按 source_url 去重。

## 作业交付边界

本设计只承诺本地可运行、可测试和可构建。华为云服务器的公网地址、账号和部署权限属于外部环境，获得后再执行线上部署和访问验证；没有线上验证证据时，不在课程提交材料中声称已经部署完成。个人 PSP、AI 协作记录和博客草稿不属于本项目源码，不纳入 Git。
