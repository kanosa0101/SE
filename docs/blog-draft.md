## 二、NABCD

### Need

论文信息分散在多个会议页面和搜索结果中，研究者很难从标题、摘要、关键词和年份维度快速观察主题变化。课程作业需要把信息采集、数据管理和可视化统计串成一个完整软件工程闭环。

### Approach

- 用单篇标题检索和 CSV 导入建立论文库。
- 用 Paper、Keyword、PaperKeyword 关系保存结构化数据。
- 用确定性的关键词归一化和 TF-IDF 补全缺失关键词。
- 用论文覆盖率计算热度，用同篇共现构造关键词关系图。
- 用会议和年份维度生成 CVPR、ICCV、ECCV 趋势序列。
- 用 Vue 页面连接真实 FastAPI 接口，而不是把演示数字写死在页面上。

### Benefit

用户可以从一篇论文追到关键词，从一个关键词追到相关论文，也可以用会议、年份和标题条件缩小范围。数据库和 API 分层后，后续替换真实数据集不需要重写前端。

### Competitors

通用学术搜索工具擅长检索，但不会直接按本作业定义的会议、热词、共现和趋势口径组织展示。CVInsight 是一个面向课程需求的轻量观察台，不宣称替代正式文献数据库。

### Delivery

本地交付包含前端、后端、SQLite schema、CSV fixture、测试、Dockerfile 和部署说明。CodeArts/华为云部分需要提交者按自己的账号完成构建和截图。

## 四、代码说明

### 后端入口

backend/app/main.py 创建 FastAPI 应用，注册论文和统计路由，配置 CORS，并在 frontend/dist 存在时挂载静态资源。生命周期函数只负责建表，不在启动时写入演示数据。

### 数据库

backend/app/models.py 定义三张表。Paper 保存论文元数据，Keyword 保存归一化关键词，PaperKeyword 保存多对多关联以及 score、method。标题在入库时生成 normalized_title，用会议、年份和规范化标题保护重复记录。

### 论文服务

backend/app/services/papers.py 负责创建、列表、更新、删除和 CSV 导入。列表接口支持 q 的标题/作者/论文编号/关键词模糊查询，也支持 conference、year、keyword 条件。CSV 导入逐行处理坏数据，成功、跳过和错误分别返回，避免一行坏数据让整个文件没有反馈。

### 关键词服务

backend/app/services/keywords.py 先处理用户提供的关键词；没有关键词时对标题和摘要执行 TF-IDF。别名归一化把视觉语言模型等表达映射到一致名称，停用词避免把常见功能词排到前面。算法是可解释的工程规则，不应在博客中写成语义理解模型。

### 统计服务

backend/app/services/metrics.py 计算论文覆盖率热度和关键词共现。统计接口只读取当前数据库，筛选条件通过 query 参数传递。前端 Top 10、关系图和趋势图消费 API 返回的数据，因此空库时显示空状态而不是显示虚构数据。

### 前端壳

frontend/src/components/AppShell.vue 提供导航、顶部状态和页面容器。OverviewView、PapersView、ImportView、TrendsView 和 AboutView 分别负责一个需求域。MetricCard、PaperTable、PaperForm、ImportResults、KeywordGraph 和 TrendChart 是可复用展示组件。

### 论文管理

PapersView 将筛选条件编码到路由 query，便于从热词图谱跳转到论文库。没有本地结果且用户输入了查询词时，页面提供在线检索按钮；在线结果必须再次确认才会创建本地记录，避免把远程结果未经检查地写入数据库。

### 导入工作站

ImportView 把单篇检索与批量 CSV 分成两个工作区。单篇流程先预览，再保存；批量流程显示文件名、大小和逐行结果。ImportResults 只渲染 API 结果，不在前端猜测数据库状态。

### 部署

Dockerfile 使用 Node 构建 Vue，再把 dist 复制到 Python 运行镜像。docker-compose.yml 用 volume 保存 SQLite 文件。deploy/README.md 只描述可执行步骤，不把没有执行过的华为云构建和公网访问写成事实。

## 八、反思

本次实现最大的收获是先建立数据模型和统计口径，再连接页面；这样页面不会因为原型中的静态数字而失去可验证性。下一步应尽早拿到真实数据源和云端环境，补齐数据许可证、部署日志和截图。对于 AI 代码，最重要的不是把生成过程隐藏，而是记录建议、判断依据、人工修改和自动化验证，让结对编程过程可追溯。
